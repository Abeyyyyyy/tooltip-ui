# Tooltip UI

Project ini merupakan bagian dari roadmap.sh dengan tujuan membuat tooltip menggunakan HTML dan CSS tanpa JavaScript.

🔗 Project URL:
https://roadmap.sh/projects/tooltip-ui

## 📌 Deskripsi
Tooltip akan muncul di atas item navigasi ketika pengguna melakukan hover. Project ini melatih penggunaan:

- CSS Positioning
- Hover Effects
- CSS Transition
- Pseudo Element (::after)

## 🚀 Cara Menjalankan Project

1. Clone repository ini
2. Buka file `index.html` di browser
3. Arahkan kursor ke menu navigasi untuk melihat tooltip
